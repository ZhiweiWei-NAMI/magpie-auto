# Native dsh 链路验证

同一个小任务要求修复 normalize_tag（去首尾空白、小写、空白串转单个连字符）和 parse_range（非负整数或有序 a-b，否则 ValueError）。early-B/early-C 保留原生单代理和可选子代理链路的实际代码、工具记录与用量；两组都自行完成，没有调用子代理。native-two-children 是修复插件后对同一功能任务的 Auto 验证，实际启动并收回两位原生调查者，代码通过六项测试。开发过程增加了边界测试，所以这些材料只验证链路，不作耗时或性能对比。

installed-plugin 是原生安装 v0.2.2 后的另一个 parse_port 编程任务。API 逐请求计量未在这些早期检查中完整采集；不把原生 inputTokens（未命中部分）当作总输入，不补造实际模型标识或耗时。正式十二题比较使用父目录的 observer 记录。
